# 10. Lessons Learned & Final Narrative

## Week-by-Week Timeline
| Phase | Activity | Technologies/Tools Used | Key Outcome |
| :--- | :--- | :--- | :--- |
| **Phase 1** | Ideation & PRD Creation | Antigravity, Markdown | Established the "Cinematic Brutalist" vision. |
| **Phase 2** | UI/UX & Design Systems | StitchMCP | Created `DESIGN.md` and established core design tokens. |

| **Phase 5** | Refactoring & Deployment | Vite, Vercel Serverless | Moved API calls to the backend and deployed to production. |

## Key Takeaways
1. **Performance over Features:** Relying on Groq's LPU inference instead of standard OpenAI endpoints made the difference between a clunky chatbot and an immersive cinematic experience.
2. **Architecture Agility:** Transitioning from a Next.js prototype to a Vite production build required flexibility but ultimately resulted in a cleaner, more tailored SPA.
3. **Design is Differentiating:** Applying a rigorous design system ("Atmospheric Intelligence") elevated standard chronological data into a premium documentary.

## Final Developer Narrative Draft
Building "Timeline AI" taught me that technical execution is only half the battle; emotional resonance and immersion are what truly engage users. By fusing high-fidelity web physics (Framer Motion, React Three Fiber) with ultra-low-latency AI inference (Groq), I was able to transform dry historical medical data into an engaging, interactive narrative. It proved that the browser can act as a cinematic canvas for education, provided the architecture supports the vision.
