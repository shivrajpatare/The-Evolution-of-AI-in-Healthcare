# 06. Tech Stack & Tooling Decisions

## Development Tools Used
*   **IDE:** VS Code / Antigravity Integrated Environment.
*   **AI Assistants:** Antigravity (powered by Gemini 3.1 Pro High)
*   **Version Control:** Git, pushed to GitHub.

## Design Tools Used
*   **UI/UX:** StitchMCP (used to automatically generate a design system from `DESIGN.md`).
*   **Asset Generation:** Antigravity Image Generator. Used for the cinematic hero backgrounds, and era-specific imagery (e.g., `slide_infographic_ai_healthcare`, `slide_title_future_ai`).
*   **Presentations:** Canva (A full 40-slide structure was generated and saved as `CANVA_DECK_GUIDE.md`).
